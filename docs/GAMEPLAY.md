# Gameplay contract

Record the authoritative gameplay rules that future contributors must preserve unless a product decision explicitly changes them.

Recommended sections:

- core loop;
- player goals and fail/win conditions;
- important state transitions;
- scoring/progression rules;
- timing/round/turn rules where applicable;
- AI/player authority assumptions;
- invariants that automated tests should protect.

Do not turn this into a design wishlist. Separate shipped/current rules from future ideas.
