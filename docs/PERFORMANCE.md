# Performance

Optional project-specific performance contract.

Record only budgets that matter for the actual runtime/platform, for example:

- frame-time/FPS target;
- startup/load time;
- memory ceiling;
- web bundle/download size;
- export/package size;
- network update/snapshot cost;
- target hardware/browser/device.

For each budget record:

- metric and measurement method;
- target/warning/fail threshold;
- reference environment;
- current baseline;
- date/build/commit of measurement.

Benchmarks detect regressions; they do not prove gameplay feel or real-world platform quality.
