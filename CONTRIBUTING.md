# Contributing

Contributions are welcome if they keep the foundation lightweight, runtime-agnostic and evidence-driven.

## Good contributions

- clearer templates;
- better examples for browser/Godot/Unity projects;
- validation/release/playtest practices that are broadly reusable;
- improvements that reduce agent conflicts or undocumented project state;
- real lessons from shipped prototypes and playtests.

## Avoid

- engine-specific policy in the shared core;
- heavyweight enterprise ceremony;
- claims that automated checks prove fun or usability;
- workflow that assumes a specific AI provider;
- templates that require external SaaS to function.

## Pull request expectations

Explain:

1. the recurring problem being solved;
2. why it belongs in the generic foundation;
3. which project types benefit;
4. validation or examples used;
5. documentation impact.
