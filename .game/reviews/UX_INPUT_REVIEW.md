# UX and input review perspective

Optional review for controls, menus, HUD and device-specific behavior.

Ask:

- Are semantic actions clear before device bindings?
- What differs between keyboard/mouse, touch and gamepad?
- Are feedback, focus, pause and error states visible?
- Are accessibility or readability regressions likely?
- Which target devices require human verification?
- Does `docs/CONTROLS.md` or platform documentation need updating?
