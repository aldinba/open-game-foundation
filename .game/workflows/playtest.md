# Playtest workflow

Before a session record:

- exact build and commit;
- device/OS/browser where relevant;
- input method;
- session type;
- explicit hypothesis/hypotheses.

During the session preserve raw observations before interpretation.

After the session:

1. keep the session note immutable;
2. normalize actionable observations as separate findings;
3. distinguish observed behavior, expected behavior and proposed solution;
4. mark implementation fixes `FIXED` only;
5. use a later named build/retest for `VERIFIED`.
