# Minimal Game Example

This is a complete, intentionally tiny example of an Open Game Foundation adoption.

Assume the game itself lives in `src/` and is a browser game. The example focuses on repository structure, not gameplay implementation.

Use it to see how the pieces fit together after adoption:

- `.game/project.json` identifies the build/runtime;
- `AGENTS.md` defines collaboration rules;
- `docs/` stores living project knowledge;
- `releases/v0.1.001/` records the current build;
- `playtests/templates/SESSION.md` captures human evidence.

The advanced layer is intentionally not fully adopted here; this example demonstrates the lightweight core.
