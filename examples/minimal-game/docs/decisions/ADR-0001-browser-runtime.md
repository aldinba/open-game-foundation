# ADR-0001 — Browser as initial runtime

- Status: accepted
- Date: 2026-10-06
- Decision owners: project maintainer
- Supersedes:
- Superseded by:

## Context

The prototype should be easy to share without requiring players to install an engine-specific build.

## Decision

Use the browser as the initial production runtime.

## Consequences

The project can be shared through a URL, while browser compatibility and performance become explicit constraints.

## Evidence

Prototype scope only; future platform decisions require new evidence.
